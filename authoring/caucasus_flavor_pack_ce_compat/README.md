# Internal CE compatibility build source

This folder is an authoring overlay inside RICE Expanded. It is merged into the CE–EPE installation preset at build time. It is not a separately enabled mod and has no descriptor.

The overlay retains unrelated CE definitions and masks the culture/pillar/name-list/rule definitions already supplied by the embedded Caucasus content. The merged package defers startup setup and the empire decision to installed CE. It targets CE 1.19.0.6, Workshop 2829397295.
